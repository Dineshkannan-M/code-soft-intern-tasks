# Helping Pets Landing Page

A professional, responsive multi-page landing page designed to raise awareness and support for homeless animals. This project serves as a social advertising platform where users can learn about pet rescue and find ways to help.

## 🌟 Features

- **Responsive Design**: Fully optimized for desktops, tablets, and mobile devices using Bootstrap.
- **Dynamic Hero Section**: Interactive carousel featuring impactful imagery and messaging.
- **Multi-page Navigation**: Includes dedicated sections for:
  - **Home**: Overview and mission.
  - **About**: Detailed information about the initiative.
  - **Why Rescue?**: Educational content on the importance of animal rescue.
  - **Contact**: A simple way for users to get in touch.
- **Modern UI**: Clean layout with fixed navigation and smooth transitions.

## 🛠️ Technologies Used

- **HTML5**: Semantic structure for the web pages.
- **CSS3**: Custom styling and layout.
- **Bootstrap 4**: Frontend framework for responsiveness and components.
- **FontAwesome**: Scalable vector icons.
- **jQuery**: JavaScript library for interactive elements (like the carousel).
